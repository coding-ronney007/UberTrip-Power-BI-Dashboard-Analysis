# 🚕 Uber Trip Analysis Dashboard | Power BI

## 📌 Project Overview
An interactive Uber Trip Analysis Dashboard developed using Microsoft Power BI to analyze ride bookings, booking amounts, trip distances, and key performance indicators (KPIs).

This project demonstrates data cleaning, data modeling, DAX measures, and interactive data visualization to support data-driven business decisions.

## 🎯 Project Objectives
- Analyze total bookings and booking amounts.
- Understand trip distance patterns.
- Monitor key performance indicators.
- Explore trends using interactive dashboard visuals.
- Present business information through clear visualizations.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization

## 📊 Key Performance Indicators
- **Total Bookings**
- **Total Booking Amount**
- **Total Trip Distance**

 ## 🔍 Business Insights

The Uber Trip Analysis Dashboard helps explore booking activity, booking amounts, and trip distance patterns.

- **Booking Trends:** Analyze booking volumes across available time periods to identify peak activity.
- **Booking Amount Analysis:** Compare booking amounts across available categories to understand revenue patterns.
- **Trip Distance Analysis:** Examine trip distances to understand ride patterns and distance distribution.
- **KPI Monitoring:** Use interactive visuals and dynamic metric selection to compare key performance indicators.

### Business Value
These insights can help stakeholders monitor ride activity, understand booking patterns, and identify areas for further operational analysis.
